Выполнение работы

Установка Git

Установка Git выполняется через менеджер пакетов.

Команда:

sudo dnf install git

Также была установлена утилита GitHub CLI:

sudo dnf install gh

Базовая настройка Git

Настройка имени пользователя:

git config --global user.name "Name Surname"

Настройка email:

git config --global user.email "email@example.com"

Просмотр конфигурации:

git config --list

Создание SSH ключа

SSH-ключ используется для безопасного подключения к GitHub.

Создание ключа:

ssh-keygen -t ed25519

Просмотр ключа:

cat ~/.ssh/id_ed25519.pub

Добавление SSH ключа в GitHub

Публичный ключ добавляется в настройки GitHub.

Основные шаги:

  1. открыть Settings
  2. перейти в SSH and GPG keys
  3. добавить новый ключ

Создание PGP ключа

PGP используется для подписи коммитов.

Создание ключа:

gpg --full-generate-key

Просмотр ключей:

gpg --list-secret-keys --keyid-format LONG

Добавление PGP ключа в GitHub

Экспорт ключа:

gpg --armor --export <PGP Fingerprint>

После этого ключ добавляется в раздел:

GitHub → Settings → GPG Keys

Настройка подписи коммитов

Настройка Git для подписи коммитов:

git config --global user.signingkey <PGP Fingerprint>
git config --global commit.gpgsign true

После этого каждый коммит автоматически подписывается.

Настройка GitHub CLI

Авторизация в GitHub CLI выполняется командой:

gh auth login

После выполнения команды происходит вход через браузер.

Создание репозитория курса

Создание репозитория через GitHub CLI:

gh repo create study_2024-2025_os-intro

Клонирование репозитория:

git clone git@github.com:<username>/study_2024-2025_os-intro.git
