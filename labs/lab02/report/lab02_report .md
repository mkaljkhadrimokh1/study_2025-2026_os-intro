# Теоретическое введение

Система контроля версий (Version Control System, VCS) предназначена для отслеживания изменений в файлах проекта. Она позволяет хранить историю изменений, возвращаться к предыдущим версиям и организовывать совместную работу над проектом.

Существует два основных типа систем контроля версий:

**Централизованные VCS**

В централизованных системах используется один центральный сервер, который хранит основную копию проекта. Примеры: CVS и Subversion.

**Распределённые VCS**

В распределённых системах каждый пользователь имеет локальную копию полного репозитория. Это повышает надёжность системы и ускоряет работу. Примеры: Git, Mercurial, Bazaar.

Git является распределённой системой контроля версий. Он хранит историю изменений проекта и позволяет разработчикам работать с локальными и удалёнными репозиториями.

Основные команды Git:

| Команда    | Назначение                     |
| ---------- | ------------------------------ |
| git init   | создание репозитория           |
| git add    | добавление файлов в индекс     |
| git commit | фиксация изменений             |
| git status | просмотр состояния репозитория |
| git push   | отправка изменений             |
| git pull   | получение изменений            |

```
git config --global core.quotepath false

Настройка начальной ветки:

```
git config --global init.defaultBranch master

```

Проверка настроек:

```

## Создание SSH ключа

Для аутентификации при работе с GitHub был создан SSH-ключ.

Создание ключа RSA:

```
ssh-keygen -t rsa -b 4096
```

Создание ключа Ed25519:

```
ssh-keygen -t ed25519
```

После генерации ключи были сохранены в каталоге:

```
~/.ssh/
```

Просмотр публичного ключа:

```
cat ~/.ssh/id_ed25519.pub
```



---

## Добавление SSH ключа в GitHub

Публичный ключ был добавлен в настройки аккаунта GitHub.

Копирование ключа:

```
xclip -i < ~/.ssh/id_ed25519.pub
```

Далее ключ был добавлен в раздел:

**GitHub → Settings → SSH and GPG Keys**


---

## Создание PGP ключа

Для подписания коммитов был создан PGP-ключ.

Команда генерации:

```
gpg --full-generate-key
```

Параметры:

* тип ключа: RSA and RSA
* размер: 4096
* срок действия: без ограничения

Просмотр списка ключей:

```
gpg --list-secret-keys --keyid-format LONG
```

Экспорт ключа:

```
gpg --armor --export <PGP Fingerprint>
```



---

## Добавление PGP ключа в GitHub

Экспорт ключа в буфер обмена:

```
gpg --armor --export <PGP Fingerprint> | xclip -sel clip
```

После этого ключ был добавлен в разделе:

**GitHub → Settings → GPG Keys**
