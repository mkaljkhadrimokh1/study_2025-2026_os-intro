## Команда man

```bash
man <команда>
```

### Описание  
Команда `man` используется для просмотра справочной информации (руководства пользователя) по командам операционной системы Linux в диалоговом режиме.  
Она предоставляет подробное описание команды, её синтаксис, доступные опции и примеры использования.

### Пример использования  
```bash
man man
```
Данная команда выводит руководство по самой команде `man`.

### Управление просмотром  
Для навигации по справочной информации используются следующие клавиши:  
- `Space` — переход на одну страницу вперёд  
- `Enter` — переход на одну строку вперёд  
- `q` — выход из режима просмотра

## Команда cd

```bash
cd [путь_к_каталогу]
```

### Описание  
Команда `cd` используется для перемещения по файловой системе операционной системы типа Linux.  
Она позволяет пользователю переходить между каталогами, используя абсолютные и относительные пути.
### Скриншот  
```markdown
![cd ](images/Screenshot 2026-03-18 095338.png)
```

Файловая система Linux представляет собой иерархическую структуру каталогов и файлов.  
Самый верхний каталог называется корневым и обозначается символом `/`.  
Он содержит системные файлы и другие каталоги.

### Особенности использования  
- `cd` — переход в домашний каталог пользователя  
- `cd ~` — переход в домашний каталог пользователя  
- `cd ..` — переход в родительский каталог  


### Примеры использования  
```bash
cd lab06
cd ..
cd ~
```

Команда  
```bash
cd ..
```
используется для перехода на один уровень выше в файловой системе.
### Скриншот  
```markdown
![..cd](images/Screenshot 2026-03-18 095338.png)
```

### Дополнительная информация  
Для получения подробной информации о команде можно использовать:  
```bash
man cd
```



### Вывод  
В результате выполнения команды были освоены основные способы перемещения по файловой системе Linux, включая использование абсолютных и относительных путей, а также переход в домашний и родительский каталоги.

## Команда pwd

```bash
pwd
```

### Описание  
Команда `pwd` (print working directory) используется для определения абсолютного пути к текущему каталогу пользователя.  
Она выводит полный путь от корневого каталога `/` до текущей директории.

### Пример использования  
```bash

```

## Команда history

### Описание  
Команда `history` используется для вывода списка ранее выполненных команд.  
Каждой команде присваивается номер, и к ней можно обратиться по этому номеру с помощью конструкции `!<номер_команды>`.  
Также возможна модификация команды из списка с использованием синтаксиса `!<номер_команды>:s/<что_меняем>/<на_что_меняем>`.

### Примеры использования  

1. Просмотр истории команд:
```bash
history
```
### Скриншот
```markdown
![history_list](images/Screenshot 2026-03-18 102857.png)
```

2. Выполнение команды по номеру:
```bash
!91
```
### Скриншот
```markdown
![history_execute](images/Screenshot 2026-03-18 102933.png)
```

3. Модификация команды из истории:
```bash
!89:s/-r/-i
```
### Скриншот
```markdown
![history_modify](images/Screenshot 2026-03-18 103139.png)
```

### Вывод  
Изучен механизм работы с историей команд, выполнение команд по их номеру и возможность их модификации.
