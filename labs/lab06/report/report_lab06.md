## Формат команды

```bash
<имя_команды> <разделитель> <аргументы>
```

## Команда man

```bash
man <команда>
```

### Описание
Команда `man` используется для просмотра справочной информации по командам Linux.

### Пример использования

```bash
man man
```

### Управление просмотром
- `Space` — переход вперёд
- `Enter` — строка вперёд
- `q` — выход

## Команда cd

```bash
cd [путь_к_каталогу]
```

### Описание
Команда `cd` используется для перемещения по файловой системе.

### Скриншот

![cd](images/Screenshot 2026-03-18 095338.png)

### Особенности
- `cd` — домой
- `cd ~` — домой
- `cd ..` — вверх

### Примеры

```bash
cd lab06
cd ..
cd ~
```

### Скриншот

![cd_up](images/Screenshot 2026-03-18 095338.png)

### Вывод
Освоена навигация по файловой системе.
