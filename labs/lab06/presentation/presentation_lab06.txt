# Слайд 3 — Формат команды

<имя_команды> <аргументы>

Пример:
man ls

---

# Слайд 4 — Команда man

Описание:  
Просмотр справочной информации о командах.

Пример:
man man

Основные клавиши:
- Space — вперед
- Enter — строка вниз
- q — выход

![](images/Screenshot 2026-03-18 095111.png)

---

# Слайд 5 — Команда cd

Описание:  
Переход между каталогами.

Основные варианты:
- cd — домашний каталог  
- cd .. — на уровень выше  
- cd ~ — домой  

![](images/Screenshot 2026-03-18 095338.png)

---

# Слайд 6 — Команда pwd

Описание:  
Показывает текущий каталог.

Пример:
pwd

![](images/Screenshot 2026-03-18 095441.png)

---

# Слайд 7 — Команда ls

Описание:  
Просмотр содержимого каталога.

Основные опции:
- ls  
- ls -a  
- ls -l  

![](images/Screenshot 2026-03-18 100642.png)

---

# Слайд 8 — Команда mkdir

Описание:  
Создание каталогов.

Примеры:
mkdir abc
mkdir -p dir1/dir2

![](images/Screenshot 2026-03-18 101821.png)

---

# Слайд 9 — Команда rm

Описание:  
Удаление файлов и каталогов.

Примеры:
rm -r dir
rm -i file

![](images/Screenshot 2026-03-18 102812.png)

---

# Слайд 10 — Команда history

Описание:  
Просмотр истории команд.

Примеры:
history
!91

![](images/Screenshot 2026-03-18 102857.png)

---

# Слайд 11 — Символ ;

Описание:  
Выполнение нескольких команд подряд.

Пример:
mkdir test; cd test
