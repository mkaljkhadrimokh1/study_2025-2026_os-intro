Слайд 3 — Формат команды

<имя_команды> <аргументы>

Пример: man ls

Слайд 4 — Команда man

Описание:
Просмотр справочной информации о командах.

Пример: man man

Основные клавиши: - Space — вперед - Enter — строка вниз - q — выход

Слайд 5 — Команда cd

Описание:
Переход между каталогами.

Основные варианты: - cd — домашний каталог
- cd .. — на уровень выше
- cd ~ — домой

Слайд 6 — Команда pwd

Описание:
Показывает текущий каталог.

Пример: pwd

Слайд 7 — Команда ls

Описание:
Просмотр содержимого каталога.

Основные опции: - ls
- ls -a
- ls -l

Слайд 8 — Команда mkdir

Описание:
Создание каталогов.

Примеры: mkdir abc mkdir -p dir1/dir2

Слайд 9 — Команда rm

Описание:
Удаление файлов и каталогов.

Примеры: rm -r dir rm -i file

Слайд 10 — Команда history

Описание:
Просмотр истории команд.

Примеры: history !91

Слайд 11 — Символ ;

Описание:
Выполнение нескольких команд подряд.

Пример: mkdir test; cd test
