# Теоретическое введение

Markdown — это лёгкий язык разметки, предназначенный для удобного форматирования текстовых документов. Он позволяет создавать структурированные документы с помощью простого текстового синтаксиса.

Основные возможности Markdown:

* создание заголовков
* форматирование текста
* создание списков
* вставка изображений
* оформление блоков кода
* добавление ссылок
* написание формул

Markdown широко используется при создании:

* документации программных проектов
* научных отчётов
* README файлов
* технической документации.

Для преобразования Markdown-файлов в другие форматы используется инструмент **Pandoc**. Он позволяет конвертировать документы в PDF, DOCX, HTML и другие форматы.

Markdown позволяет выделять текст:

Полужирный текст:

## Использование Makefile

Для автоматизации сборки был использован следующий Makefile:

FILES = $(patsubst %.md, %.docx, $(wildcard *.md))
FILES += $(patsubst %.md, %.pdf, $(wildcard *.md))

FILTER = --filter pandoc-crossref

%.docx: %.md
  pandoc "$<" $(FILTER) -o "$@"

%.pdf: %.md
  pandoc "$<" $(FILTER) -o "$@"

all: $(FILES)

clean:
  rm $(FILES)

Сборка выполняется командой:

make
