## Актуальность

* широко используется в разработке программного обеспечения
* применяется для написания документации и отчётов

# Основные элементы Markdown

Markdown поддерживает:

* заголовки
* форматирование текста
* списки
* ссылки
* изображения
* код
* формулы

---

# Заголовки

Пример:

```
# Heading 1
## Heading 2
### Heading 3
```


---

# Форматирование текста

Пример:

```
**bold**
*italic*
***bold italic***
```

Результат:

**bold**
*italic*
***bold italic***

---

# Списки

Неупорядоченный список

```
- item 1
- item 2
- item 3
```

Упорядоченный список

```
1. first
2. second
3. third
```

---

# Код

Пример блока кода

```bash
git status
git commit
```



---

# Использование Pandoc

Pandoc позволяет преобразовывать Markdown документы.

Пример команды:

```
pandoc report.md -o report.pdf
```

```
pandoc report.md -o report.docx
```
